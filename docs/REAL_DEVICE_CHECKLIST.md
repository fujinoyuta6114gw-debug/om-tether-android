# OM‑1 Mark II 実機確認チェックリスト

本番データのない予備SDカードと、十分に充電したカメラ／Android端末で実施してください。最初の試験ではUSBハブを挟まず直結します。

## 0. 事前設定

- [ ] カメラのファームウェア版を記録した
- [ ] カメラ電源OFF → USB-C接続 → 電源ONの順で操作した
- [ ] カメラ画面で `0 RAW/Control` を選択してOKを押した
- [ ] カメラの画質設定を記録した
- [ ] カード1／カード2の画質振り分けとファイル番号を記録した
- [ ] Androidの空き容量を5 GiB以上確保した
- [ ] USB-Cケーブルがデータ通信対応であることを確認した

## 1. 読み取りだけの接続確認

- [ ] アプリがUSB許可ダイアログを表示した
- [ ] 接続表示が `OM‑1 Mark II` になった
- [ ] 診断画面にVID `33A2`、PID `0136` が出た
- [ ] 診断画面にメーカー `OMSYSTEM` または `OLYMPUS` が出た
- [ ] 対応命令に `9484`、`9481` が含まれた
- [ ] ケーブルを抜くとアプリが切断状態へ戻った

ここで機種名が違う、またはPTP responseが連続して失敗する場合は撮影へ進まず、診断ログを保存します。

## 2. ライブビュー

- [ ] 再接続後10秒以内にライブビューが表示された
- [ ] 30秒間継続してもアプリとカメラが固まらない
- [ ] 停止表示が出た場合、「再接続」でUSB/PTPセッションを作り直してフレーム受信へ復帰する
- [ ] 再接続後の診断ログに `DeviceReset 0x66 completed` またはフォールバック記録がある
- [ ] 復帰中に停止前の静止画がライブ映像として残らない
- [ ] ピンチ拡大と「リセット」が動く
- [ ] ヒストグラムが被写体に合わせて変化する
- [ ] 明るい被写体で白飛び警告が出る
- [ ] しきい値スライダーで警告範囲が変わる
- [ ] アプリをバックグラウンドへ移すとUSBライブビュー取得が止まり、復帰後に再開する

## 3. JPEGを1枚だけ撮影・保存

- [ ] アプリで「スマホにJPEG」を選んだ
- [ ] シャッターボタンを1回だけ押した
- [ ] カメラが1回だけ撮影した
- [ ] アプリに撮影JPEGが即時表示された
- [ ] `Pictures/OM Tether/<日付>` にJPGが1つ作成された
- [ ] 画面の「専用保存先」が実際の `Pictures/OM Tether/<日付>` と一致する
- [ ] JPGをAndroidで開けた
- [ ] カメラのSDカード上の元画像が残っている
- [ ] カメラがRAWのみの場合は `_PREVIEW.JPG` と画質制限の警告が表示された
- [ ] 次にカメラ本体のシャッターボタンで1枚撮影し、追加操作なしでJPGが同じ専用保存先へ届いた

## 4. RAWを1枚だけ撮影・保存

- [ ] アプリで「スマホにRAW」を選んだ
- [ ] シャッターボタンを1回だけ押した
- [ ] 撮影プレビューが表示された
- [ ] `Pictures/OM Tether/<日付>` にORFが1つ作成された
- [ ] ORFをPCへコピーし、OM Workspace等で現像できた
- [ ] Android側へJPEGが余分に保存されていない
- [ ] カメラのSDカード上の元画像が残っている
- [ ] 次にカメラ本体のシャッターボタンで1枚撮影し、追加操作なしでORFが同じ専用保存先へ届いた

最初は `カード1＝RAW／カード2＝JPEG` で上の両方を確認します。次にカードの割り当てを入れ替え、同じ結果になることを確認します。取得できない場合は、診断ログの `USB event`、`New handles` と各 `ObjectInfo` のstorage/name/format/sizeを確認します。

## 5. 露出操作

- [ ] カメラ側で絞りを変更すると、約3秒以内にアプリ表示が追従する
- [ ] カメラ側でシャッター速度を変更すると、約3秒以内にアプリ表示が追従する
- [ ] カメラ側でISOを変更すると、約3秒以内にアプリ表示が追従する
- [ ] 接続中に「露出同期中」と表示される
- [ ] 絞りの選択肢がカメラの現在レンズと一致する
- [ ] raw値40が `f/4.0` と表示される
- [ ] 1/125秒などが分数で表示される
- [ ] シャッター速度の変更がカメラ表示へ反映される
- [ ] ISO変更が反映される
- [ ] 露出補正変更が反映される
- [ ] WB変更が反映される
- [ ] 書き込み不可の項目がUIで無効になっている

表示名だけが不正で撮影値は正しい場合、診断ログにあるproperty code、data type、raw value、enum一覧を基に表示変換を調整します。

## 6. 安定性

- [ ] 50枚連続で欠落・重複・破損がない
- [ ] 30分のライブビューで端末が過熱停止しない
- [ ] 保存中にケーブルを抜いても、既存ファイルが壊れない
- [ ] 再接続後にアプリ再起動なしで復帰できる
- [ ] Android画面回転後も接続・保存が継続する
- [ ] 保存容量不足を模擬した場合、保存済みファイルと失敗ファイルが区別して表示される

50枚試験が通るまでは、仕事の撮影で唯一の保存経路として使用しないでください。カメラ内SDカードへの同時記録を維持します。
